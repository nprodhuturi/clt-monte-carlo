# Evaluating Central Limit Theorem Convergence

Developed reproducible Monte Carlo simulations in R (10,000 repetitions at each sample size, with a fixed random seed) to measure how quickly sampling distributions approach normality across multiple population distributions and sample sizes. Evaluated convergence using histograms, Q–Q plots, skewness, excess kurtosis, and the simulated versus theoretical standard error, then examined how non-identical observations and heavy-tailed populations affect classical Central Limit Theorem results.
